Week 2a — LLM Foundations

Run an open-weight model on your own machine

Today we are going to run an LLM locally: a real open-weight model, on your laptop, no API key, no cloud.

1. Install Ollama

Ollama is the tool we’ll use to download and run open-weight models.

  • macOS
  • Windows
  • Linux

Download the app from ollama.com/download, drag it into Applications, and open it once. Then verify in Terminal:

ollama --version

If you use Homebrew, brew install ollama works too.

Download and run the installer from ollama.com/download. Then open PowerShell and verify:

ollama --version

One command:

curl -fsSL https://ollama.com/install.sh | sh

Then verify:

ollama --version

2. Download and run a model

We’ll use Qwen 3.5, an open-weight model family that comes in sizes from 0.8B to 122B parameters. One command downloads the default size (about 6.6 GB) and drops you into a chat:

ollama run qwen3.5

Type a message and watch it answer, token by token — that streaming is the autoregressive loop from lecture, live. Type /bye to exit the chat.

Pick a size that fits your machine. The default is a good middle ground, but if your laptop has 8 GB of RAM or you want a faster download, grab a smaller one; if you have a big machine, try a bigger one:

ollama run qwen3.5:2b     # small and quick — any laptop
ollama run qwen3.5:4b     # 8 GB RAM
ollama run qwen3.5:9b     # 16 GB RAM (the default)
ollama run qwen3.5:27b    # 32 GB+ RAM

The full list of sizes is on the model page. Rule of thumb: the download size is roughly the RAM the model needs while running.

Also grab these two for class. They are tiny (a few hundred megabytes each, seconds to download, run on anything) and we will use them together in a demonstration:

ollama pull qwen2.5:0.5b        # instruction-tuned
ollama pull qwen2.5:0.5b-base   # raw pretrained — no post-training

Same architecture, same size, same training data — the only difference is what happened after pretraining. Ask them both a question in class and you will see exactly what that difference buys. (ollama pull downloads without starting a chat; ollama run does both.)

3. Commands you’ll actually use

ollama list        # models you have downloaded
ollama ps          # models currently loaded in memory
ollama rm qwen3.5  # delete a model and free the disk space

And inside a chat, /bye exits.

Why we’re doing this

Ollama also runs a local API server (at localhost:11434), which means later in the course your agents can call a model that is entirely yours. We will use that for local inference.
