Week 6a — Planning and Task Decomposition

Pull today’s files

Today’s folder has the notebook, the same policy document we have been searching since Week 5, and the tools from Week 4.

Get today’s files

From your course project folder (agentic-ai-course), in the VS Code terminal:

  • macOS
  • Windows
  • Linux
cd lecture-files
git pull
cd ..
cp -r lecture-files/W06a W06a
cd lecture-files
git pull
cd ..
Copy-Item -Recurse lecture-files/W06a W06a
cd lecture-files
git pull
cd ..
cp -r lecture-files/W06a W06a

Then open the notebook from your W06a copy, not from lecture-files, and select the .venv kernel.

Nothing new to install

The notebook runs on what you already have. If W05b worked for you, today works.

Use the same embedding model you used in Week 5

The notebook rebuilds the vector store from scratch, so nothing carries over from a Week 5 kernel. Pick a provider in section 0 and leave the others alone, the same way you did before.

Two rate limits, not one

Today’s notebook makes more model calls per question than anything we have run so far. A planner, a search per step, a review, and sometimes a replan and another round of searches.

The Gemini free tier has two separate limits, and you can hit either:

limit what it feels like
per minute 15 requests a 429 that clears in under a minute
per day 500 requests a 429 that tells you to come back in an hour or more

The per-minute one recovers while you read the next cell. The daily one does not. If you re-run a notebook repeatedly you will find it, and then you are done with Gemini for the day.

The fix is to switch the model cell in section 0 to Ollama and re-run from there.
